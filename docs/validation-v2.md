# 双赛题 V2 验证报告

## 做了什么

按官方赛题详情重新核对输出格式和公开集计分方式，保留原版官方运行器、框架、验证视频及标注。

- 乒乓球用触台前后更长一段轨迹的速度变化，区分相邻的真实触台与轻微起伏。正面隔帧版本在公开集上 F1 下降，因此保留上一版的逐帧推理方式。
- 篮球逐帧检测，复用图像归一化缓冲，批量计算球衣颜色和脚下区域特征。新版场内球员筛选模型在 34 场训练比赛的 39,522 个检测框样本上拟合；留出 7 场比较时，筛选精确率从 77.8% 提到 89.8%，召回率从 95.8% 变为 95.4%。公开验证视频未参与模型拟合。
- 新增公开复评分脚本：除了各视角落点 F1、篮球 IDF1 和 MOTA，还报告同帧命中、像素误差和各片段的漏检、误检，并检查是否跑完清单中的全部帧。已检查临界容差、重复匹配、空标注帧和篮球每帧 15 框上限等情况。

## 验证结果

完整跑完乒乓球 15 段、篮球 2 段，共 3,609 帧；新版官方输出格式校验 0 错误、0 警告。准确率按公开规则复算。

| 指标 | 上一版 | V2 |
| --- | ---: | ---: |
| 乒乓球整体 F1 | 81.28% | 83.42% |
| 乒乓球 0° F1 | 74.42% | 74.42% |
| 乒乓球 45° F1 | 74.36% | 79.49% |
| 乒乓球 90° F1 | 93.94% | 93.94% |

| 篮球 MOTA | 63.04% | 73.58% |

乒乓球完全命中标注帧的落点由 55 个增至 57 个。篮球误框由 2,393 个减至 1,320 个，漏框由 1,304 个减至 1,290 个，局部身份切换由 108 次变为 110 次，整段身份一致性仍有所提升。

同一台电脑、同一 DirectML 推理后端、CPU 解码、两个任务顺序执行。这里的 FPS 按总帧数除以处理时间计算，时间不含初始化。

### 数据使用

工程中的全部 17 段公开验证视频都参与测试和方案比较。篮球训练数据覆盖 68 段视频，对画面和检测框抽帧采样，留出比赛场次验证。乒乓球此前用官方训练数据抽取 2,599 个三帧窗口做微调；微调未超过原权重，因此提交版保留官方小球权重。本轮乒乓球的提升来自落点候选判断。

## 遗留问题

公开验证集已经用于方案选择，不能当作独立盲测。篮球公开验证只来自一场比赛，严重遮挡后仍会出现身份切换。官方隐藏集、Linux 容器和双 4090 的速度尚未实测；ZIP 是工程包，正式外部平台提交要在官方基础镜像上构建并导出 Docker TAR。
